# 05편 막힌 곳 재시도와 쿠팡 최저가 탐색 (2026-11-21)

담당 [AI]. 운영자 결정(2026-11-21): 우회해 얻을 수 있는 정보는 얻고, 불가능한 곳은 포기, 중대하면 구체적으로 요청. 최저가는 쿠팡 필수 탐색(제휴 고려).
적용 기준: robots.txt만 막은 곳은 단건 조회(`docs/blog/robots-exceptions.json`), 기술적 차단(403·차단 화면·봇 확인·로그인)은 우회하지 않음. 사용자 에이전트는 바꾸지 않았다.

검색 요약에 보인 쿠팡 값 [스니펫, 미검증, 캐시 시점 불명]: 와토스 WP20 정품 4,940원, WP20-1 4,100원, 역류방지 WP20 5,300원, 국산 WP20 볼탑 4,300원(배송비 3,000원), 필밸브+전용 조립공구 세트 8,980원(2개 11,990원), 대림바스 투피스 절수형 볼탑 필밸브+조립공구 무료배송 13,900원.
읽는 법: 다나와 WP20 최저가 2,450원은 배송비 3,000원 별도라 합계 5,450원이다. 쿠팡이 무료배송이면 배송비 포함 합계는 쿠팡이 더 쌀 수 있다. 확인하려면 쿠팡 원문 값이 필요하다.

## 3. 운영자에게 요청할 것

- [현장] 쿠팡 파트너스 가입 → Open API 키(Access Key·Secret Key) 발급 → 이 환경의 환경 변수 `COUPANG_PARTNERS_ACCESS_KEY`, `COUPANG_PARTNERS_SECRET_KEY`로 등록. HMAC 서명이라 프록시 주입 방식은 쓸 수 없다. API는 최종 승인 계정만 쓸 수 있다는 2차 자료가 있다 [미검증].
- [현장] 키 전 임시안: 쿠팡 앱에서 아래 검색 결과 첫 화면을 캡처해 올리면 AI가 판독해 `직접:` 행으로 기록한다. 검색어: 와토스 WP20, 와토스 WP250, 와토스 WP21, 대림바스 투피스 필밸브, 대림 원피스 볼탑 CC-213, 이누스 원피스 필밸브, 계림 원피스 필밸브, 아메리칸스탠다드 필밸브, 멍키스패너 200mm.
- [판단] 제휴 링크를 넣으면 고지 문구가 "협찬·제휴 없이 작성한 글입니다"에서 쿠팡 파트너스 고지로 바뀌어야 한다(R14 §고지). 링크는 준비물 절 안에만 둔다(check-claims guide_affiliate_place).
