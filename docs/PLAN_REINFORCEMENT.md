# FixAtlas 기획 보강안 (2026-11-17)

> 근거: `docs/research/R1~R6`(시장·타겟·경쟁·수요·연계사업/법규·공개가격) + 저장소 분석 + 구현 검증.
> 표기: **[검증]** 원문을 직접 열어 확인 · **[조사]** 조사 에이전트 보고(2차 출처 포함) · **[estimate]** 산식 명시 추정 · **[unverified]** 미확인(확인 경로 병기) · **[판단]** 작성자 판단.

## 0. 결론 (먼저)

1. **방향은 유지, 중심축을 바꾼다.** "커뮤니티형 MVP"가 아니라 **"견적 위치 확인" 한 가지 약속**에 모든 것을 맞춘다. 견적을 받은 직후 *"같은 모델·증상에서 이 금액이 어디쯤인가"*를 근거와 함께 답하고, 데이터가 부족하면 **부족하다고 말한 뒤** 공식 기준가격·안전한 자가점검으로 대신 답한다. (구현 완료, 아래 7장)
2. **가장 큰 위험은 콜드스타트**다. 168개 모델×증상 셀에서 RFP 목표(제보 100건)가 `n≥5`로 채울 수 있는 셀은 **최대 20개(12%)**다. 목표를 "건수"가 아니라 **"집중 셀 n≥5 달성 수"**로 바꾼다. (3장)
3. **수요·SEO 가설은 아직 증명되지 않았다.** 롱테일 검색량은 도구 접근 문제로 **하나도 검증하지 못했다**. 런칭 4주 안에 Search Console로 직접 측정하고, 기준 미달이면 SEO 확장을 멈춘다. (5장)
4. **수익은 12개월 이후 문제**다. 소모품 제휴는 요율이 낮고[조사] 중고·수리 리드는 데이터 임계치가 필요하다. 초기 비용은 최소로 두고 게이트 기준으로만 확장한다. (6장)
5. **법무 선결 과제**: 개인정보처리방침·약관(임시조치 절차)·영수증 마스킹은 공개 전 필수. 코드로 막을 수 있는 것(비공개 저장, 공개 응답에서 식별정보 제거)은 처리했다. (8장)

**TAM/SAM/SOM [estimate, 산식은 R1 3장]** — 연간 유상 수리 의사결정 owner: 저 25만 / 기준 61만 / 고 117만 명, 무선청소기가 약 79%. SOM(1년차 도달)은 620 / 7,300 / 56,000명, **기여자 12 / 370 / 4,500명**.
→ 90일로 환산하면 기여자 **3 / 91 / 1,110명**(`370×90/365`)으로, 기준 시나리오가 RFP 목표 100건과 같은 규모다. 즉 **목표는 가능한 범위이나 여유가 없고, 보수 시나리오에서는 시딩 없이 불가능**하다.

해석: ① 소비자원 접수 연 100~300건은 TAM의 0.1% 미만이라 "시장 크기" 신호가 아니라 "불만의 방향" 신호다. ② 무선청소기가 TAM의 대부분이므로 무선 데이터(배터리 교체 중심)를 로봇만큼 중시해야 한다. ③ 해외(EU 2024/1799)는 청소기가 부속서에 있으나 참조 규정(666/2013)이 배터리식·로봇을 제외해 **실효 수리 의무는 아직 불명**[조사].

## 3. 타겟(ICP)과 KPI 재설정 (R2)

**1차 ICP [조사+판단]**: 30~40대, 60만 원 이상 중국 브랜드 로봇청소기 보유자, **보증 만료 직전·직후 견적을 받은 순간**.
근거: 소비자원 신청자 30~40대 67.9%(268건 중 182건) · 로보락·드리미 고가 점유율 합 60%+ · 중국 브랜드 보증 1년·배터리 제외 · 공식 센터 22곳 수준[조사 R2]. **보유자 인구통계 설문은 존재하지 않음** → 가정이므로 인터뷰로 검증.
**2차**: ① 삼성·LG 보증 만료 후 부품+출장비 합산 견적 불투명한 사용자 ② 보증 기간 내 하자 분쟁 중인 사용자(하자 건 구제율 56.5%).
법정 기준: 전기청소기 품질보증 1년·부품보유 제조일로부터 7년(공정위 고시 2025-14호)[조사]. "9년"은 2011년 행정예고안일 뿐.

**검증 인터뷰 질문 5개 (런칭 전 10명)**: R2 문서 참조 — 첫 행동, 견적 적정성 판단 방법, 재구매 전환 기준(%), 보증·배터리 조건 인지, 공개 시 신뢰 조건·제보 의향.

## 6. 연계 사업 로드맵 (R5)

수익은 **데이터 임계치 → 게이트 → 시도** 순서. 아래 임계치는 내부 가설 [판단].

| 기간 | 시도 | 진입 게이트 |
|---|---|---|
| 0–3개월 | 제휴 링크(표시 준수 필수), 중고 시세 링크, 데이터 정제 | 등록 모델 ≥30, 확인 제보 ≥300, 월 UV ≥5천 |
| 3–12개월 | 소모품 SKU 매핑 확장, 업체 프로필+견적 요청 파일럿 1개 지역 | 상위 20모델 각 ≥10건, 월 UV ≥2만, 견적 요청 ≥월 100 |
| 12–36개월 | 수리점 건당 과금, 케어플랜 리드, B2B 대시보드, 신뢰도 지수(분모 확보 후) | 상위 50모델 각 ≥30건, 업체 ≥20곳, 제조사 LOI 3곳 |

기대가치 순위: ① 소모품 제휴 ② 중고·트레이드인 연결 ③ 수리 리드젠 ④ 케어플랜 리드 ⑤ B2B ⑥ 신뢰도 지수.
**현실 점검**: 쿠팡파트너스 가전·디지털 최대 1%(24시간 쿠키)는 2차 자료뿐[unverified, 대시보드 확인] → 객단가 3~5만 원 × 1% = **건당 300~500원**. 월 100건 전환이어도 3~5만 원. 서버비 이하이므로 **초기엔 수익화로 판단하지 말 것**. 벤치마크: RepairPal은 인증 업체망(추천 건당 $50 또는 10%)이 수익이며 견적은 공임 가이드·OEM 부품가·지역 공임 기반이었다(사용자 제보 아님) — **데이터 소스 다변화**가 교훈. 한국은 "매칭"보다 "기사 직영망"(마이스터즈)이 성장 중.
정책 순풍은 약함: 순환경제사회 전환 촉진법 제20조는 **노력 의무**, 시행령 제10조의3 대상에 청소기 포함 여부 불명[조사].

## 9. 90일 실행 계획과 중단 기준

| 주 | 할 일 |
|---|---|

**게이트·중단 기준 [판단, 수치는 조정 가능]**
- 4주차: 제보 시작→완료 전환 ≥30%, 견적 비교 사용 ≥50회 — 미달이면 폼 길이·로그인 시점 재설계.
- 8주차: 비용 페이지 **월 노출 ≥ 10,000**(CTR 3~8%면 방문 300~800 ≈ RFP 5,000의 6~16%, 초기 램프 체크포인트 [판단])이 안 나오면 SEO 확장 중단, 커뮤니티·콘텐츠 제휴 중심으로 전환 검토. (RFP 방문 5,000 자체는 노출 63k~167k가 필요 [estimate, R4])
- 12주차: 집중 셀 n≥5가 **5개 미만**이면 수요/공급 가설 실패로 보고 피벗(B2B 데이터 수집, 대상 변경)하거나 중단. 건수 100을 채우기 위한 시딩 인플레이션 금지.

## 11. 조사의 한계 (읽을 때 주의)

- 조사 에이전트 6개가 **공유 WebSearch 한도(200회)를 소진**해 후반 교차검증이 줄었고, 네이버 카페·블로그·Instagram·Reddit·dyson.co.kr 등은 도구가 열람하지 못했다. "아무도 하지 않는다"는 결론은 **보통 신뢰**다.
- 시장 수치 대부분이 언론 보도(출처 간 불일치)이며, 점유율·규모는 범위로 읽어야 한다.
- 법령 조문은 law.go.kr 본문이 렌더되지 않아 미러로 읽었다. **법률 자문이 아니다.**
- 제가 직접 원문과 대조한 것은 KCA 공지(74.5%·204/70건·유형 비율·56.5%/84.1%), 삼성 소모품샵 2개 제품 가격, LG 배터리 2종·출장비 4종이다. 나머지는 보고서 신뢰도를 따른다.
