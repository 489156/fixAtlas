# R5. 인접 사업 + 규제 (FixAtlas / 고장도감)

작성일 2026-11-17 / 방법: 웹 데스크리서치만 / **본 문서는 법률 자문이 아닌 리서치 노트임.**
표기: `[U]` = 미검증(검증 경로 병기). 법령 조문은 law.go.kr 본문이 fetch로 렌더되지 않아 nepla.ai 미러로 내용을 읽고 law.go.kr URL을 병기함(최종 확인은 law.go.kr).

## 핵심 결론
1. 단기 수익은 제휴 커머스(소모품·부품)와 중고/트레이드인 연결이 현실적이나, **가전 카테고리 쿠팡 요율은 낮다(1% 보도, [U])**. 소모품 중심 SKU와 중고 연결로 보완해야 함.
2. 수리 중개는 한국에서 "단순 매칭"보다 "기사 네트워크 직접 운영" 모델이 성장 중(마이스터즈). 매칭 수수료 공개 수치는 못 찾음.
3. 법적 1순위 리스크는 **영수증 이미지의 개인정보**와 **업체명 후기의 명예훼손·임시조치 운영**.
4. 블루프린트의 "FCC 회로도는 public domain"은 **오류**: 미 연방법은 연방 공무원이 작성한 저작물만 보호 제외. 신청자가 제출한 도면은 신청자 저작물이며 기밀 처리도 흔함.

3. **Supabase**: 서울 리전 확인(프로젝트 생성 후 변경 불가 여부 [U: Supabase 문서 확인]), DPA 체결, 백업·로그 위치 점검.
4. **72시간 유출 대응 플레이북** + 접속기록 보관 (시행령 제39조, 제40조).

6. **후기 작성 가이드**: 체험·사실 중심, 비방·추측·실명 개인 금지, 업체 실명은 사업자명만.
7. **제휴·보상 표시**: 제휴 링크 글 상단 단정형 표기, 포인트 보상 후기 표시 (심사지침 2024-12-01).
8. **가격 게시 방식**: 집계·기간·표본 수 표기, 개별 업체 실시간 가격 비교 금지.

10. **중개 기능 도입 전 점검**: 수리 예약·결제 추가 시 통신판매중개 신고·고지(전자상거래법 제12조, 제20조) 선행.
