# R2. 타깃 사용자 리서치 (고장도감 / FixAtlas)

작성일 2026-11-17 · 웹 데스크리서치만 사용 · 날짜 없는 공식 페이지는 "열람일 2026-11-17"로 표기

## 결론 (3줄)
1. 소비자원 수치는 대체로 맞다. 단, "56.5%"는 제품 하자 건만의 구제율이고(계약·거래 건은 84.1%), 무선청소기 피해구제 수치와 2025 연보 순위는 공개 자료에서 못 찾았다.
2. 법정 보증은 전기청소기 1년·부품보유 제조일로부터 7년이고, 중국 브랜드(로보락 등)는 사실상 1년 보증+배터리 제외라서 "보증 만료 직후 견적 쇼크"가 핵심 순간이다. 수리 전 견적 공개를 명시한 브랜드는 다이슨 외에 못 찾았다.
3. 1차 ICP는 "30~40대, 60만원 이상 중국 브랜드 로봇청소기 보유자, 보증 만료 전후"로 제안한다. 단 보유자 인구통계 설문은 없고, 소비자원 신청자 연령(30~40대 67.9%)만 대용 근거다.

## ICP 제안
**1차 ICP: 중국 브랜드 프리미엄 로봇청소기 보유자 (30~40대, 보증 만료 전후)**
- 근거: 신청자 30~40대 67.9%[K2], 로보락·드리미 고가 점유율 합계 60% 이상[M1], 보증 1년·배터리 제외[R1], 센터가 22곳 수준이라 AS 불만이 반복됨[R2][M2], 센서·작동불가·누수가 상위 하자[K1].
- 트리거: 증상 발생 후 센터 견적 수령 직전·직후. 약속: "같은 모델이 실제 낸 수리비" 열람.
- 가정(미검증): 수도권 아파트, 맞벌이·신혼. 보유자 통계는 없으므로 인터뷰로 확인.

**2차 A: 삼성·LG 로봇·스틱청소기 보유자.** 방문 AS 체계와 출장비 인상(LG 28,000원)[L2], 모터 10년·배터리 소모품 구조[S1][L1] 때문에 보증 만료 후 부품·배터리·출장비 합산 견적이 불투명. 근거는 구조적이고 설문 근거는 없음.

**2차 B: 보증기간 내 하자 분쟁 중인 사용자.** 하자 건 구제율 56.5%[K1], 판매자의 사용자 과실 주장. 증상·증빙 사례가 협상 근거가 됨. 다이슨 무선청소기(2년 보증, 과거 AS 불만[D2])는 3순위 후보.

**검증용 인터뷰 질문 5개**
1. 마지막으로 청소기가 고장 났을 때 가장 먼저 한 행동과 이유는? (검색/센터 전화/DIY/재구매)
2. 센터 견적을 받았을 때 그 금액이 적정한지 어떻게 판단했고, 어디에서 비교했나요?
3. 수리비가 새 제품 가격의 몇 %를 넘으면 재구매를 택하나요? 실제 수리 포기 경험은?
4. 보증기간·배터리 제외 조건을 구매 전에 알았나요? 보증 만료 뒤 비용을 예상한 적이 있나요?
5. 같은 모델 사용자의 실제 수리비·소요기간이 공개된다면 어떤 정보가 있어야 믿고, 직접 올릴 의향은?

## 확인 못 한 항목
- 무선청소기 소비자원 피해구제 건수·유형·구제율, 2025 피해구제 연보 청소기 순위 (경로: kca.go.kr 소비자정보 > 피해구제 통계 또는 data.go.kr "피해구제 접수 품목별")
- 고시 별표Ⅳ 내용연수(전기청소기) 현행값 (경로: law.go.kr 소비자분쟁해결기준 별표Ⅳ)
- 에코백스·드리미·아이로봇 한국 공식 보증·택배비·점검비 (경로: 각사 한국 고객지원 페이지 또는 고객센터)
- 삼성 현행 출장비, 모든 브랜드의 수리 전 견적 공개 정책 (경로: 삼성 서비스요금 산정기준 탭, 센터 문의)
- 보유자 인구통계, 첫 행동·AS 만족도·지불의사 설문 (경로: 엠브레인 트렌드모니터, 오픈서베이, 자체 설문)
- 네이버 카페명·회원수, 디시 갤러리, 다나와·쿠팡·당근·오픈채팅 활동량 (경로: 각 플랫폼 직접 확인)
- 검색 도구 한도 소진으로 일부 추가 교차검증을 하지 못했다. 다이슨·로보락 모델별 일부 수치는 공식 페이지 직접 열람 대신 검색 요약에 의존했다.
