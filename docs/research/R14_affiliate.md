# R14. 제휴 링크(어필리에이트) 도입 — 검증된 사실과 판단 (2026-11-18)

방법: 공식 페이지를 직접 열어 확인(curl 기본 UA, robots.txt 허용 경로만; WebFetch). 열지 못한 것은 `[unverified]`와 확인 경로를 붙였다. 인용은 출처당 15단어 이하.
표기: **[공식]** 운영사·정부 원문 / **[2차]** 언론·블로그 / **[판단]** 우리 해석·권고(근거 없음 또는 간접 근거).

## 0. 결정에 필요한 7줄

1. **제휴 수수료는 명시적으로 표시 대상이다.** 2024-12-01 개정으로 구매링크 판매실적에 따른 수수료가 예시에 들어갔고, 블로그는 **제목 또는 첫 부분**에 표시해야 한다. "받을 수 있음" 같은 조건부 문구는 불명확 예시다. [공식]
2. **"광고·제휴 없음" 문구는 제휴 링크가 들어간 글에서 반드시 빠져야 한다.** 남겨 두면 기만 광고 위험이 있다. [판단, 표시광고법 제3조①2 근거]
3. **네이버 쇼핑 커넥트(정식 명칭 '쇼핑 커넥트', 브랜드 커넥트 안의 어필리에이트 기능)**는 2025-07-23 정식 출시됐다. 블로그는 **누구나** 쓸 수 있고(이용 제한 상태 제외), 판매자가 정한 상품별 요율을 받는다. 다른 상품이 팔린 간접 실적은 1.8%다. **정해진 고지 문구를 그대로** 써야 한다. [공식]
4. **쿠팡 파트너스 공식 페이지는 robots.txt `Disallow: /`라 열지 않았다.** 요율·쿠키·정산·필수 문구는 모두 [unverified]다. 2차 자료끼리도 가전 요율이 1~3%로 서로 다르다.
5. **네이버가 외부 제휴 링크(쿠팡)를 강등한다는 공식 발표는 찾지 못했다.** 공식 문서는 쇼핑 커넥트 링크에 대해서만 "불이익 없음"이라고 밝힌다. 외부 링크에 대한 "저품질" 주장은 블로거 사이의 소문이다.
6. **구조적 이해상충**: 수수료는 부품·소모품·새 제품 구매에서만 생긴다. 서비스센터 수리는 수익이 0원이다. 쿠팡은 유상 보증을, 쇼핑 커넥트는 렌탈·정기구독을 수수료 대상에서 뺀다. 그래서 "교체" 쪽으로 기우는 유인이 생긴다. [공식 사실 + 판단]
7. **쿠팡 광고 스크립트·배너는 피한다.** 개인정보위가 2026-06에 쿠팡 파트너스 광고로 이용자가 **클릭하지 않아도** 타사 활동기록이 수집된 건에 과징금을 부과했다. 자체 사이트에는 텍스트 링크만 쓴다. [2차 보도 + 판단]

### 3-B. 소문(블로거·마케터 주장, 공식 근거 없음)

- "쿠팡 파트너스 링크를 넣으면 저품질·노출 누락" → 공식 확인 없음. 한 마케팅 사이트(2026-10)는 파트너스 단축 링크의 noindex가 글 전체를 색인에서 빼지는 않는다고 분석했다(제3자 분석).
- "단축 URL로 바꾸면 저품질을 피한다" → 근거 없음. 쇼핑 커넥트는 링크 변조를 금지하고, 아마존은 단축 서비스를 명시적으로 금지한다(업계 기준).
- "고지 문구를 하단에 두면 쿠팡 수익이 몰수된다" → 커뮤니티 사례 주장 [2차]. 법상 하단 표기는 이미 부적절하므로 논점이 아니다.

## 5. FixAtlas 적용안 [판단]

1. **글 분리**: 비용 데이터·방법론·제보 요청 글은 링크 없이 유지하고 "광고·제휴 없음"을 그대로 쓴다. 제휴 링크는 "부품·소모품 구매 가이드" 글에만 둔다.
2. **링크 글 고지**(제목 + 본문 최상단, 본문보다 크게·다른 색):
   - 제목 접두어: `[광고·제휴]`
   - 1행: "이 글의 일부 링크는 제휴 링크입니다. 링크로 구매하면 고장도감이 수수료를 받습니다. 수리·교체 판정은 제휴와 무관하게 [판정 기준]을 따릅니다."
   - 쇼핑 커넥트를 쓰면 공식 문장을 그대로 덧붙인다. 쿠팡을 쓰면 통용 문장을 쓰되 쿠팡 원문으로 재확인한다.
   - 쓰지 말 것: "받을 수 있음", AD·PR·partnership, "제휴 링크" 단독, #내돈내산
3. **링크 옆 라벨**: `(제휴)`. 지침상 의무는 아니고 근접 원칙을 보강하는 장치다.
4. **자체 사이트**: 쿠팡 배너·위젯 스크립트는 넣지 않는다. 개인정보위 2026-06-11 의결: 쿠팡 광고가 실린 사이트·앱 방문 시 "이용자가 해당 광고를 클릭하지 않더라도" 접속기록이 수집됐다(1,117만여 명, 과징금 2,011억원; 뉴시스 2026-06-11, 수집 기간 종료 연도는 기사 간 표기 차이).
5. **제보 보상**: 제보에 포인트를 주면 그 후기에도 표시가 필요하다(R8, 2025-12 안내서).
