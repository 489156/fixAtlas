방법: WebSearch 18회(2회는 도메인 차단 오류), WebFetch로 개별 공개 글만 열람했습니다. 모든 관찰의 열람일은 **2026-11-18**입니다. 인용은 출처당 15단어 이하이고, 블로거 개인정보는 기록하지 않았습니다(블로그명·채널명만 적음).
**중요한 한계**: 네이버 블로그는 이 환경에서 검색도 열람도 차단되어 직접 연 글이 0건입니다(R12 §1의 robots.txt 확인과 같은 결과). 그래서 레퍼런스 10곳은 티스토리 3, 브런치 1, 독립·기업 사이트 6으로 구성했습니다.

## 결론 3줄

1. 비용·정보성 글의 공통 뼈대는 **요약 박스 → 목차 → 표 → FAQ·체크리스트**입니다. 그런데 출처와 기준일을 모두 적은 곳은 10곳 중 1곳(FoxCG)뿐이었고, 표본 수를 적은 곳은 0곳이었습니다. FixAtlas의 데이터 표기는 분명한 차별점입니다.
2. 반응 지표가 보인 3곳(뉴닉 읽음 132,882, 여기어때 조회 370, 티스토리 댓글 7)은 모두 **1인칭 목소리(직접 경험이나 에디터 의견)와 해요체**를 썼습니다. 표만 있는 글보다 "표 + 실물 사진 + 짧은 경험담" 조합이 맞습니다. 다만 n=3이라 상관관계일 뿐입니다.
3. 쇼핑·예약·금융 링크가 있는 4곳 모두 대가성 표기가 없었습니다. 공정위 지침은 2024-12-01부터 제목이나 첫 부분에 표기하도록 요구합니다. FixAtlas는 첫 줄에 "광고·제휴 없음 / 기준일"을 박아 신뢰 장치로 쓰시면 됩니다.
