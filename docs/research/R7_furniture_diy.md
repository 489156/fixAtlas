# R7. 가구 자가수리 (FixAtlas / 고장도감)

작성 2026-11-17 / 웹 데스크리서치만 / 페이지 확인일은 별도 표기 없으면 2026-11-17.
표기: `[U]` = 미검증, `[H]` = 내부 가설(점수·판단), `(2차)` = 언론·블로그 경유.

## 결론 3줄
1. **가구는 추가할 가치가 있으나 "2순위 카테고리"로 시작.** 온라인 가구 거래액은 연 5.7조원 규모로 커지고 있고, 분쟁은 품질(51%)·반품비·배송에 몰려 있습니다. 반면 소비자원 2025 조사의 "수리 경험 상위 5개 품목"에 가구는 없고, 청소기(9.2%)는 들어 있습니다. 그래서 청소기 데이터 수집을 대체하지 말고, 구조가 같은 "출장비·부품값이 정상인가" 축으로 확장하는 편이 맞습니다.
2. **가격을 모으기 쉬운 근거가 이미 공개되어 있습니다.** 브랜드 출장비가 공개돼 있고(한샘 5만/6만원, 현대리바트 3만원, 일룸 2.2만원), 시디즈·일룸·듀오백은 부품 가격을 공개합니다. 이케아는 소형 부품을 무료로 줍니다. 이 공개값이 "견적 정상 여부" 비교의 기준선이 됩니다.
3. **시작 주제: 문짝·경첩, 서랍 레일, 소파 꺼짐·가죽(견적형), 의자 바퀴.** 의자 가스실린더는 Caution으로 둡니다(분해는 Do Not DIY). 서랍장 벽고정은 가격 데이터는 적지만 안전 콘텐츠로 반드시 넣습니다.
