# 수요·검색어(GEO) 분석 — 1주차 3편 (2026-11-18)

**목적**: 글을 쓰기 전에 네 가지에 답한다. 누가 읽는가, 무엇이 급한가, 그 사람이 충분히 많은가, 어떤 문장으로 검색하는가. 원고 front matter의 `reader`·`need`·`urgency`·`scale`·`queries`가 이 문서의 요약이고, `check-claims`가 빠진 항목과 본문이 다루지 않는 검색어를 실패 처리한다.

## 1. 무선청소기 배터리 (`naver/01`)

- **독자**: 삼성 BESPOKE 제트·LG 코드제로 A9/A9S 같은 무선(스틱형)청소기를 2년 넘게 써서 사용 시간이 줄어든 사람
- **급한 정도**: 중간. 매일 쓰는 청소기가 제대로 돌지 않고, 10만 원대 지출을 결정해야 한다
- **규모(대리 지표, 2026-11-18 관측)**
  - LG 고객지원 「배터리 교체 주기와 수명이 짧아지는 원인과 관리방법」 조회 250,422회 (갱신 2026-10-30)
  - LG 「흡입력이 약해요(배터리 방전)」 조회 51,926회
  - LG 공식몰 A9/A9S 배터리 상품 리뷰 1,677개, R9 배터리 61개
- **실제 질의 → 글이 답하는 자리**

| 자동완성에서 확인된 질의 | 글의 소제목·문단 |
|---|---|
| 무선청소기 배터리 수명 / 교체 주기 / 코드제로 배터리 수명 | 「무선청소기 배터리 수명과 교체 주기」 + LG 정상 사용 시간 표 |
| 코드제로 배터리 충전 안됨 / 방전 / a9 배터리 리셋 | 「충전이 안 될 때 교체 전에 확인할 것」 (LG 공식 점검 4항목. 공식 "리셋" 절차는 없음) |
| 코드제로 배터리 무상 교체 | 「무상 교체가 되는 경우」 (2019 보도자료의 2년 보증 + 현재 안내의 차이 → 고객센터 직접 확인 칸) |
| 무선청소기 배터리 교체 비용 / 코드제로 a9 배터리 가격 / 삼성 제트 배터리 교체 | 제목 + 「정품 배터리 가격」 |
| 비스포크 제트 배터리 호환 | 부품번호·적용 모델 목록 확인 문단 |
| 무선청소기 배터리 리필 / 셀프 교체 / 교체 업체 | 「리필(셀 교체) 업체를 써도 되나」 + 주의 문단 |
| 무선청소기 배터리 버리기 | **미반영**. 공식 폐기 안내를 확인하지 못함 → 다음 갱신 때 지자체·제조사 안내로 추가 |

- **분류 결정**: 자동완성에서 "로봇 청소기 배터리 교체 비용"과 "무선 청소기 배터리 교체 비용"은 따로 검색된다. 그래서 1편은 무선청소기만 다룬다. 로봇청소기 배터리(삼성 제트 봇 77,000원, LG R9 190,000원·회원할인가 180,500원, 2026-11-18 공식몰)는 별도 글로 옮겼다(`BLOG_PLAN.md` 6-2). "로봇청소기 배터리 폭발·화재" 질의도 그 글에서 다룬다.

## 2. LG전자 출장비 (`naver/02`)

- **독자**: LG전자 에어컨·세탁기·냉장고·청소기 고장으로 기사 방문을 예약하려는 사람
- **급한 정도**: 높음. 예약 직전이고, 시간대만 바꿔도 5,000~10,000원이 달라진다
- **규모**: 자동완성에 "lg 출장비"의 제품별 변형(에어컨·세탁기·냉장고·서비스센터·기사·인터넷 기사)이 다수 있다. 정량 지표는 확보하지 못했다
- **질의 → 자리**: 제품별 질의(에어컨·세탁기·냉장고 출장비)는 「에어컨·세탁기·냉장고 출장비도 같은가」가 답한다(요금 안내에 제품별 구분이 없고, 에어컨 설치비만 별도). "삼성 출장비" 질의도 많지만 공식 요금표의 적용 시점이 불명확해 싣지 않았다. 확인되면 별도 글로 낸다.

## 3. 로봇청소기 고장·분쟁 (`naver/03`)

- **독자**: 로봇청소기가 고장 나 제조사·판매처와 교환·환불을 다투는 사람, 그리고 구매 전에 AS 분쟁 위험을 따지는 사람
- **급한 정도**: 높음. 수십만~백만 원대 제품이 멈춘 상태에서 업체와 다투고 있다
- **규모**: 소비자원 피해구제 신청 274건(2022~2025.6). 소비자원까지 온 건만 센 숫자다. 보도자료 조회 5,036회(관측). 자동완성에 "로봇청소기 고장·고장 증상·as·as 비용·as 비교·환불"
- **질의 → 자리**: 고장 증상은 「로봇청소기 고장 증상, 어떤 하자가 많았나」, 환불·교환은 「교환·환불을 요구할 수 있는 기준」과 피해구제 순서, AS는 「맡기기 전 점검」이 답한다.
- **미반영**: 브랜드별 AS 비교(에코백스·드리미·클리엔·에브리봇 등, "as 비교/순위" 질의). 소비자원 자료에 브랜드 구분이 없다 → 제보 데이터가 쌓이면 다룬다.

## 4. GEO 원칙 (네이버 검색·AI 답변 공통, 근거 `R12`)

1. **질문형 소제목 + 바로 답하는 첫 문장.** AI 인용에서 유일하게 유의했던 콘텐츠 요인은 "질문과 맞는 제목·문단"이었다(R12 G5). 소제목은 자동완성 질의의 말로 쓴다.
2. **모델명·부품번호·숫자는 본문 텍스트로 쓴다.** 이미지 속 숫자는 검색·AI가 읽지 못할 수 있다.
3. **태그는 실제 질의를 붙여 쓴 형태로 5~10개.** 예: `코드제로배터리무상교체`. 네이버가 태그를 순위에 얼마나 반영하는지는 공개되지 않았다 [unverified]. 그래서 태그는 분류·내부 탐색용으로 보고, 검색 매칭은 제목·소제목·첫 문단이 맡는다고 본다.
4. **AI 검색 인용 경로**: 네이버 블로그는 ChatGPT·Perplexity·Claude 검색 봇을 막는다(R12 §1). 그래서 같은 사실을 자체 사이트의 사전 렌더링 페이지에도 둔다(`PUBLISHING_AND_GEO.md` §2). 네이버 AI 브리핑은 네이버 블로그를 인용하므로 블로그 쪽 질문형 구조도 유지한다.

## 4-1. 자동 공백 분석 (2026-11-18, `node scripts/demand-research.mjs`)

`queries`를 시드로 구글 자동완성을 다시 모아 본문이 답하는지 대조했다. 원자료는 `docs/research/data/suggest/<slug>.json`이다. 판정은 단어 포함 기준이라 "답했다"가 곧 충분히 답했다는 뜻은 아니다.

| 글 | 실제 검색어 | 본문이 다룸 | 다루지 않는 검색어의 성격 | 조치 |
|---|---|---|---|---|
| 01 배터리 | 24 | 21 | 다른 브랜드(테팔·일렉트로룩스), 커뮤니티명(디시) | 한 글 한 품목 원칙상 본문에 넣지 않음. 브랜드별 글 후보 |
| 02 LG 출장비 | 16 | 14 | "lg 인터넷 (기사) 출장비" 2개 — LG유플러스 인터넷 설치 수요 | 가전 수리와 다른 수요라 제외 |
| 03 로봇청소기 | 21 | 9 | 브랜드별 고장(에코백스·삼성·클리엔·에브리봇·드리미·imou·샤오미) 8개, A/S 평판(디시·순위) 2개, 직배수 누수 2개 | 이 글은 교환·환불 판단이 주제. 브랜드별 증상과 직배수 누수는 별도 글 후보 |

태그 후보는 본문이 답하는 검색어에서만 뽑는다. 처음 구현에서는 "lg인터넷기사출장비"·"삼성로봇청소기고장"처럼 본문이 답하지 않는 태그가 후보로 나왔다. 태그가 본문에 없는 답을 약속하면 독자가 바로 이탈하므로 막았다. 붙여 쓴 검색어("lg에어컨")도 영문·한글 경계에서 나눠 대조한다. 처음에는 이를 한 단어로 보고 2편의 "lg에어컨 기사 출장비"를 놓쳤다.

## 5. 남은 일과 담당

- [현장] 네이버 검색광고 API 키 발급(계정 소유자만 가능). → [AI] `demand-research`가 질의별 월간 검색량(PC·모바일)을 조회해 `scale:`과 이 표에 채운다. 구글 자동완성만으로는 규모를 판단할 수 없다.
  - 제약: 이 API는 요청마다 비밀 키로 서명해야 해서, 네트워크 프록시가 헤더를 끼워 넣는 방식으로는 쓸 수 없다. 비밀 키를 이 클라우드 환경에 둘지, 사용자 PC에서 실행할지가 [판단]이다.
- [AI] 질의별 네이버 상위 5개 글의 제목·첫 문단·이미지 비교(R10). 네이버 검색·블로그는 robots.txt로 자동 접근을 막아 지금은 하지 않는다. 사용자 PC 브라우저로 AI가 열어 보는 방식을 허용할지가 [판단]이다.
